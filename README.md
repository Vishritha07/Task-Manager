# Task Manager

A full-stack Task Manager web application built using HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Features

- Add new tasks
- View all tasks
- Change task status
- Delete tasks
- Move tasks up and down
- Save task order in MongoDB
- Keep tasks saved after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
